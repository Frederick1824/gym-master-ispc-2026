# GYM MASTER · ISPC 2026

Simulador académico de Matemática y Lógica. React + Vite + TypeScript, sin backend.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir la URL que muestre Vite (normalmente http://localhost:5173).

## Funciones
- Simulador con planes de 3, 5 y 30 días; descuentos excluyentes; promoción familiar.
- Validaciones didácticas y lógica proposicional con explicaciones expandibles.
- Laboratorio con tablas de verdad, fidelización aritmética y finanzas.
- Casos predefinidos, registro local y exportación CSV.
- Presentación guiada con navegación manual.

## Advertencias académicas
- El documento original presenta inconsistencias en algunos ejemplos de fórmulas y en la definición exacta de antigüedad. Se tomó la regla explícita **más de 6 meses**.
- En finanzas, se usó **consumo × tarifa** para luz y agua, coherente con los ejemplos numéricos del ABP.
- La simulación no procesa cobros reales ni registra personas reales.
- Revisar con el grupo la interpretación de promociones y cobro antes de presentar.
